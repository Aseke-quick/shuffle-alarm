# .10x — team state

State of the 10x-Team process (`/10x-Team:10x-team`), used for big, open work such as the redesign. Normal `PLAN.md` tasks still run through `/next-task`.

- `status.md`: the phase and the task progress. `handoff.md`: context for the next role.
- `decisions/<role>/`: each role's notes. `_index.md` holds what holds across the project; `<feature-slug>.md` is one area.
- `specs/`: approved designs. `adrs/`: architecture decision records. `reviews/`: QA and security reports.
- `docs/DECISIONS.md` stays the project's main decision log. An ADR here gets a short entry there that links to it, so the two never disagree. Notes tagged `[DISCOVERED]` were read from the code and docs on 2026-10-29, not decided in this process.
