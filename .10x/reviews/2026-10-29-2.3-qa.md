## Findings
- **Low: `sourceUrl` is a path in the repo, not a URL.** For these clips it is `tool/generate_placeholder_library.dart`, because the code repo is private and has no public address. `CLAUDE.md` asks only that the field is there. Task 3.5 (`tool/check_licenses.dart`) must accept a repo path for license `original`.
- **Low: the tool writes the whole manifest.** docs/DECISIONS.md 2.3 records it. Before Phase 3 adds real tracks, change the tool to keep the other entries, or retire it.
- **Info: the sync writes to the browser console in release builds** (`debugPrint`), one line at the first visit. It is not an error, and it helps testers.
- **Info: Riverpod tries a failed sync again by itself**, up to 10 times, so a database that cannot open logs the failure more than once. The Alarms tab already shows that error.
