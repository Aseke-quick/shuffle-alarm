# Wakemix

[![CI](https://github.com/Aseke-quick/shuffle-alarm/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/Aseke-quick/shuffle-alarm/actions/workflows/ci.yml)

**A new mix every morning.** Wakemix is an alarm that plays a different sound every 30 seconds until you get up. One Flutter codebase for web, Android, iOS, macOS, Windows and Linux. The web version comes first, as the test version.

Until 2026-10-29 the app was called Shuffle Alarm. The package name `shuffle_alarm`, the app IDs, the database name, the repo names and the site address keep the old name ([docs/DECISIONS.md](docs/DECISIONS.md), task 2.2a).

**Web test version:** https://aseke-quick.github.io/shuffle-alarm/ (work in progress). Every push to `main` publishes the built files to the `gh-pages` branch.
